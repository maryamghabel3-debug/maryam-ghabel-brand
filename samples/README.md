# 📁 پوشه نمونه‌ها (Samples)

این پوشه برای آپلود ویدیوهای نمونه و منابع آموزشی مریم قابل است. با دیدن این نمونه‌ها، سیستم می‌تواند الگوهای بصری و ریتم موشن‌ها را استخراج کند.

---

## 📂 ساختار پوشه‌ها

### `reference-videos/`
ویدیوهایی که سبک، ریتم و کیفیت نهایی مورد نظر مریم هستند. مثلاً:
- موشن گرافیک‌هایی که دوست داری
- سبک‌های مختلف (whiteboard، 2D، مینیمال، و غیره)
- ویدیوهایی که از نظر بصری «تمیز» به نظر می‌رسند
- **نام‌گذاری پیشنهادی:** `01-style-name-source.mp4`, `02-...mp4`

### `inspiration/`
تصاویر، عکس‌ها، screenshot از سبک‌های بصری:
- رنگ‌ها، فونت‌ها، چیدمان‌ها
- پینترست، دربیان‌بوک و...
- **نام‌گذاری:** `palette-01.jpg`, `typography-02.png`, ...

### `educational-materials/`
هر منبع آموزشی که مریم در اختیار دارد:
- ویدیوهای آموزش موشن گرافیک
- PDF یا سند درباره سبک‌ها
- لینک‌ها (در یک فایل links.md)

---

## 🎬 نحوه آپلود

### روش ۱: آپلود مستقیم در GitHub (ساده)
1. برو به: https://github.com/maryamghabel3-debug/maryam-ghabel-brand
2. روی پوشه `samples/reference-videos/` کلیک کن
3. دکمه **Add file → Upload files** را بزن
4. ویدیوها را drag & drop کن
5. Commit changes

### روش ۲: خط فرمان (برای چند فایل)
```bash
cd maryam-ghabel-brand
cp /path/to/your-video.mp4 samples/reference-videos/
git add samples/
git commit -m "chore(samples): add reference video"
git push
```

### روش ۳: ارسال برای من
اگر فایل‌ها بزرگ هستند (بیشتر از ۲۵MB)، می‌توانی:
- لینک Google Drive / Dropbox بدهی
- یا به چند فایل کوچک‌تر تقسیم کنی

## 📋 برای هر نمونه چه اطلاعاتی بدی

برای هر ویدیوی نمونه، لطفاً در فایل `notes.md` (در همان پوشه) بنویس:

```
## 01-name.mp4
- **چی دوست داری در این نمونه:** ریتم تایپوگرافی + حرکت خطوط
- **چی دوست نداری:** رنگ‌ها خیلی شلوغه
- **ستون محتوایی پیشنهادی:** ستون ۱ (الگوهای ناخودآگاه)
```

---

## 🎯 بعد از آپلود

وقتی نمونه‌ها رو آپلود کردی، به من بگو:
1. چند تا ویدیو گذاشتی
2. در کدام پوشه

سپس من:
1. فریم‌های کلیدی هر ویدیو رو استخراج می‌کنم
2. الگوی بصری مشترک رو پیدا می‌کنم (رنگ، فونت، ریتم، حرکت)
3. موشن نمونه با سبک مشابه می‌سازم
4. نتیجه رو برای بازبینی نشون می‌دم

## ⚙️ ابزارهایی که نصب کردم برای ساخت موشن بهتر

- ✅ **edge-tts** (Microsoft Azure Neural voices) — صدای فارسی fa-IR-DilaraNeural با کیفیت بالا
- ✅ **faster-whisper** — برای استخراج word-level timing برای سینک دقیق زیرنویس
- ✅ **Pillow + arabic-reshaper + python-bidi** — تایپوگرافی فارسی حرفه‌ای (مثل سیستم الینا)
- ✅ **ffmpeg** — ترکیب ویدیو + صدا + زیرنویس

این ابزارها دقیقاً همانهایی هستند که در ریپو elina-radman استفاده شده.
