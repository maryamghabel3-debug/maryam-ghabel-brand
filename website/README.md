# 🌐 سایت مریم قابل — روان‌شناس بالینی

سایت شخصی-حرفه‌ای مریم قابل، روان‌شناس بالینی.

## 🎨 مشخصات

- **دامنه:** maryamghabel.ir
- **زبان:** فارسی (RTL)
- **پالت رنگ:** سرمه‌ای + بژ + طلایی
- **فونت:** Vazirmatn
- **تکنولوژی:** Next.js 16 + TypeScript + Tailwind CSS 4 + shadcn/ui

## 📄 صفحات

1. **خانه** (`/`) — Hero + معرفی + خدمات + چرا مریم + نظرات + CTA
2. **خدمات** (`/services`) — ۵ ستون محتوایی تفصیلی + رویکرد درمانی
3. **درباره من** (`/about`) — داستان شخصی + تخصص‌ها + رویکرد
4. **رزرو جلسه** (`/booking`) — فرم رزرو با فیلدهای کامل
5. **تماس** (`/contact`) — راه‌های ارتباطی + فرم تماس

## 🚀 اجرا

```bash
cd website
bun install
bun run dev
# http://localhost:3000
```

## 📦 Build

```bash
bun run build
bun run start
```
