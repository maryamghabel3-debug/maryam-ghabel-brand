## 🔧 فرآیند تولید

این موشن با ترکیب چند تکنولوژی ساخته شده:

۱. **تولید تصاویر کلیدی** — ۵ تصویر با AI image generation با پرامپت‌های دقیق برای هر سکانس
۲. **تبدیل به فریم‌های متحرک** — با ffmpeg و افکت zoompan (ken burns)
۳. **تایپوگرافی فارسی** — با ffmpeg drawtext و فونت Vazirmatn Bold
۴. **نریشن فارسی** — تولید صدا با TTS (سرعت ۰.۸۵ برای لحن آرام)
۵. **موسیقی پس‌زمینه** — یک tone ملایم با ffmpeg sine wave
۶. **میکس و خروجی نهایی** — ترکیب ویدیو + صدا با ffmpeg
