# Maryam Ghabel Clinical — WordPress Theme

قالب وردپرس سفارشی برای **مریم قابل | روان‌شناس بالینی** ([maryamghabel.ir](https://maryamghabel.ir))

قالب حرفه‌ای، مینیمال و کمی هنری با پشتیبانی کامل از **RTL**، فونت **Vazirmatn**، و سازگار با **Elementor** و **WPForms**.

## نصب کامل قدم‌به‌قدم

### مرحله ۱: نصب وردپرس روی هاست cPanel

1. وارد **cPanel** هاست خود شوید.
2. به بخش **Softaculous Apps Installer** → **WordPress** بروید.
3. روی **Install Now** کلیک کنید و اطلاعات زیر را پر کنید:
   - **Domain**: `maryamghabel.ir`
   - **Directory**: خالی بگذارید (نصب در ریشه)
   - **Site Name**: `مریم قابل | روان‌شناس بالینی`
   - **Site Description**: `روان‌شناسی عمیق برای بزرگسالان موفق`
   - **Admin Username**: یک نام کاربری امن (نه admin!)
   - **Admin Password**: حداقل ۱۶ کاراکتر، ترکیبی از حروف/اعداد/نمادها
   - **Admin Email**: ایمیل معتبر شما
4. روی **Install** کلیک کنید و صبر کنید تا نصب کامل شود.

### مرحله ۲: نصب قالب

**روش A — از طریق پیشخوان وردپرس:**

1. پوشه‌ی `maryam-ghabel` را به فایل ZIP فشرده کنید (`maryam-ghabel.zip`).
2. وارد پیشخوان وردپرس شوید: `https://maryamghabel.ir/wp-admin`
3. به **نمایش → پوسته‌ها** بروید.
4. روی **افزودن پوسته‌ی جدید** → **بارگذاری پوسته** کلیک کنید.
5. فایل `maryam-ghabel.zip` را انتخاب کنید و روی **هم‌اکنون نصب کن** کلیک کنید.
6. بعد از نصب، روی **فعال‌کردن** کلیک کنید.

**روش B — از طریق FTP/cPanel File Manager:**

1. وارد **cPanel → File Manager** شوید.
2. به مسیر `public_html/wp-content/themes/` بروید.
3. فایل ZIP قالب را در این پوشه آپلود و اکسترکت کنید.
4. مطمئن شوید پوشه‌ی `maryam-ghabel` درست کنار پوسته‌های پیش‌فرض است.
5. به پیشخوان وردپرس → **نمایش → پوسته‌ها** بروید و قالب **Maryam Ghabel Clinical** را فعال کنید.

### مرحله ۳: نصب پلاگین‌های مورد نیاز

به **افزونه‌ها → افزودن جدید** بروید و موارد زیر را نصب و فعال کنید:

| پلاگین | کاربرد | الزامی؟ |
|---|---|---|
| **Elementor** | ساخت صفحات بصری | ✅ الزامی |
| **WPForms** | فرم رزرو و تماس | ✅ الزامی |
| **Yoast SEO** | بهینه‌سازی موتور جستجو | توصیه‌شده |
| **Wordfence Security** | امنیت و فایروال | توصیه‌شده |
| **UpdraftPlus** | بکاپ‌گیری خودکار | توصیه‌شده |
| **Autoptimize** یا **WP Rocket** | بهینه‌سازی سرعت | اختیاری |

### مرحله ۴: Import محتوای نمونه

1. به **ابزارها → وارد کردن (Import)** بروید.
2. روی **WordPress** کلیک کنید و اگر پلاگین Importer نصب نیست، روی **Install Now** بزنید.
3. بعد از نصب و فعال‌سازی، به **Run Importer** بروید.
4. فایل `sample-content.xml` (که در پوشه‌ی قالب است) را آپلود کنید.
5. روی **Upload file and import** کلیک کنید.
6. در مرحله‌ی تنظیمات:
   - تیک **Download and import file attachments** را نزنید (محتوای نمونه تصویر ندارد).
   - یک نویسنده‌ی موجود را انتخاب کنید یا نام نویسنده‌ی جدید را وارد کنید (مثلاً «مریم قابل»).
7. روی **Submit** کلیک کنید.

پس از Import، ۵ صفحه با اسلاگ‌های `home`, `services`, `about`, `booking`, `contact` ساخته می‌شوند.

### مرحله ۵: تنظیمات اولیه وردپرس

#### ۵-۱. تنظیم منوها

1. به **نمایش → فهرست‌ها** بروید.
2. یک فهرست جدید بسازید با نام «منوی اصلی».
3. صفحات **خانه، خدمات، درباره من، رزرو جلسه، تماس** را به آن اضافه کنید.
4. در پایین، **Display location** را روی **منوی اصلی** تنظیم کنید.
5. ذخیره‌ی فهرست.

#### ۵-۲. تنظیم صفحه‌ی اصلی

1. به **تنظیمات → خواندن** بروید.
2. در بخش **Your homepage displays**:
   - گزینه‌ی **A static page** را انتخاب کنید.
   - **Homepage**: صفحه‌ی «خانه» را انتخاب کنید.
   - **Posts page**: یک صفحه‌ی خالی به نام «وبلاگ» بسازید و انتخاب کنید (اختیاری).
3. ذخیره‌ی تغییرات.

#### ۵-۳. تنظیم پیوندهای یکتا

1. به **تنظیمات → پیوندهای یکتا** بروید.
2. گزینه‌ی **Post name** را انتخاب کنید.
3. ذخیره‌ی تغییرات (اگر فایل `.htaccess` قابل نوشتن نباشد، وردپرس کد لازم را نمایش می‌دهد).

#### ۵-۴. تنظیم زبان و تاریخ

1. به **تنظیمات → همگانی** بروید.
2. **Site Language**: `فارسی` را انتخاب کنید.
3. **Timezone**: `Asia/Tehran` را تنظیم کنید.
4. **Date Format**: `j F Y` (تاریخ شمسی) — برای این کار پلاگین **WP Persian** یا **Jalali Date** را نصب کنید.
5. ذخیره.

### مرحله ۶: تنظیم قالب (Customizer)

به **نمایش → سفارشی‌سازی** بروید و بخش‌های زیر را تنظیم کنید:

#### ۶-۱. هویت سایت
- **Site Title**: مریم قابل
- **Tagline**: روان‌شناس بالینی
- **Site Icon**: لوگوی مریم قابل را آپلود کنید (۱۲۲×۱۲۲ پیکسل).
- **Logo**: لوگوی اصلی را آپلود کنید.

#### ۶-۲. تنظیمات قالب مریم قابل (پنل اختصاصی)

پنل **«تنظیمات قالب مریم قابل»** شامل بخش‌های زیر است:

**هویت برند:**
- نام برند
- شعار برند

**اطلاعات تماس:**
- ایمیل (پیش‌فرض: `info@maryamghabel.ir`)
- شماره تلفن (placeholder — مریم قابل پر می‌کند)
- واتساپ، اینستاگرام، تلگرام (placeholder — مریم قابل پر می‌کند)
- نشانی (placeholder)
- ساعات کاری (پیش‌فرض: «شنبه تا چهارشنبه، ۹ تا ۱۸»)

**ادغام فرم‌ها:**
- شناسه‌ی فرم رزرو WPForms
- شناسه‌ی فرم تماس WPForms

**رنگ‌های برند:** (در صورت نیاز به تغییر، قابل تنظیم)

**امکانات قالب:**
- فعال/غیرفعال‌سازی Tailwind CSS CDN
- فعال/غیرفعال‌سازی انیمیشن‌های ورود

#### ۶-۳. ساخت فرم رزرو در WPForms

1. به **WPForms → Add New** بروید.
2. قالب **Appointment Form** یا یک فرم خالی را انتخاب کنید.
3. فیلدهای زیر را اضافه کنید:
   - **Name** (نام و نام خانوادگی)
   - **Email** (ایمیل)
   - **Phone** (شماره تماس)
   - **Dropdown**: «نوع جلسه» با گزینه‌های: تماس اولیه، جلسه فردی، جلسه گروهی
   - **Dropdown**: «نحوه برگزاری» با گزینه‌های: آنلاین، تلفنی، حضوری
   - **Paragraph Text** (توضیح کوتاه)
   - **Checkbox** (موافقت با محرمانگی)
4. ذخیره و **Save** کنید.
5. شناسه‌ی فرم (مثلاً `123`) را از URL یادداشت کنید.
6. به **Customizer → تنظیمات قالب مریم قابل → ادغام فرم‌ها** بروید و شناسه را وارد کنید.
7. همین کار را برای فرم تماس انجام دهید.

### مرحله ۷: ساخت صفحات با Elementor (اختیاری)

برای سفارشی‌سازی بیشتر، می‌توانید صفحات را با Elementor ویرایش کنید:

1. به **صفحات → همه‌ی صفحات** بروید.
2. صفحه‌ی مورد نظر را باز کنید.
3. روی **Edit with Elementor** کلیک کنید.
4. با درگ-اند-دراپ و ویجت‌های Elementor، صفحه را طراحی کنید.
5. پالت رنگ قالب در **Site Settings → Global Colors** در دسترس است.
6. فونت Vazirmatn در **Site Settings → Global Fonts** قابل انتخاب است.

### مرحله ۸: نکات امنیتی

#### ۸-۱. امنیت وردپرس
- نام کاربری ادمین را `admin` نگذارید.
- پسورد قوی حداقل ۱۶ کاراکتر استفاده کنید.
- احراز هویت دو مرحله‌ای (2FA) با پلاگین **Wordfence Login Security** یا **Two Factor** فعال کنید.
- پلاگین **Wordfence Security** را نصب و فعال کنید.

#### ۸-۲. امنیت فایل‌ها
- فایل `wp-config.php` را یک پوشه بالاتر از `public_html` منتقل کنید (اگر هاست اجازه می‌دهد).
- در فایل `.htaccess` این کد را اضافه کنید:
  ```apache
  # Block wp-config.php
  <files wp-config.php>
      order allow,deny
      deny from all
  </files>

  # Disable directory browsing
  Options -Indexes

  # Block XML-RPC (if not needed)
  <Files xmlrpc.php>
      order deny,allow
      deny from all
  </Files>
  ```

#### ۸-۳. پشتیبان‌گیری
- پلاگین **UpdraftPlus** را نصب کنید.
- بکاپ‌های خودکار هفتگی (دیتابیس + فایل‌ها) را فعال کنید.
- مقصد بکاپ: Google Drive یا Dropbox (نه روی همان هاست).

#### ۸-۴. بروزرسانی
- وردپرس، پلاگین‌ها و قالب را همیشه بروز نگه دارید.
- بکاپ قبل از هر بروزرسانی.

#### ۸-۵. SSL / HTTPS
- گواهی SSL رایگان از **Let's Encrypt** در cPanel فعال کنید.
- پلاگین **Really Simple SSL** را برای redirect خودکار HTTP → HTTPS نصب کنید.

## عیب‌یابی (Troubleshooting)

### قالب نمایش داده نمی‌شود؟
- مطمئن شوید پوشه‌ی `maryam-ghabel` در `wp-content/themes/` است.
- فایل `style.css` در ریشه‌ی پوشه باشد.
- `functions.php` بدون خطای PHP باشد (در `wp-config.php` روی `WP_DEBUG = true` بگذارید تا خطاها نمایش داده شوند).

### فونت Vazirmatn بارگذاری نمی‌شود؟
- مطمئن شوید اینترنت سایت دسترسی به `cdn.jsdelivr.net` دارد.
- در صورت تحریم، از روش‌ی میزبانی محلی (مراجعه به `assets/fonts/README.md`) استفاده کنید.

### منو نمایش داده نمی‌شود؟
- مطمئن شوید یک منو در **نمایش → فهرست‌ها** ساخته و در **Display location → منوی اصلی** تنظیم شده باشد.

### فرم رزرو کار نمی‌کند؟
- مطمئن شوید WPForms فعال است.
- شناسه‌ی فرم درست در Customizer وارد شده باشد.
- اگر شناسه‌ی فرم خالی باشد، فرم پیش‌فرض قالب نمایش داده می‌شود.
