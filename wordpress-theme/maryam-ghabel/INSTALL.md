# INSTALL.md — راهنمای سریع نصب قالب مریم قابل

این فایل، راهنمای فشرده‌ی نصب است. برای توضیحات کامل‌تر به `README.md` مراجعه کنید.

---

## پیش‌نیازها

- وردپرس 6.0+
- PHP 8.0+
- هاست cPanel با دسترسی FTP/File Manager
- فایل قالب: `maryam-ghabel.zip` (یا پوشه‌ی `maryam-ghabel`)

---

## قدم ۱ — نصب وردپرس

اگر وردپرس هنوز نصب نیست:

1. وارد **cPanel** شوید.
2. **Softaculous → WordPress → Install Now**
3. دامنه: `maryamghabel.ir`، مسیر: خالی.
4. نام کاربری ادمین: یک نام امن (نه `admin`).
5. رمز عبور: حداقل ۱۶ کاراکتر.
6. **Install** را بزنید و چند دقیقه صبر کنید.

---

## قدم ۲ — آپلود و فعال‌سازی قالب

1. پوشه‌ی `maryam-ghabel` را به‌صورت فایل ZIP (`maryam-ghabel.zip`) دربیاورید:
   ```bash
   cd /home/z/my-project/wordpress-theme/
   zip -r maryam-ghabel.zip maryam-ghabel/
   ```

2. وارد پیشخوان وردپرس شوید: `https://maryamghabel.ir/wp-admin`

3. به **نمایش → پوسته‌ها → افزودن پوسته‌ی جدید → بارگذاری پوسته** بروید.

4. فایل `maryam-ghabel.zip` را انتخاب کنید → **هم‌اکنون نصب کن** → **فعال‌کردن**.

اگر از FTP استفاده می‌کنید:
- پوشه‌ی `maryam-ghabel` را در `public_html/wp-content/themes/` آپلود کنید.
- سپس به پیشخوان بروید و قالب را فعال کنید.

---

## قدم ۳ — نصب پلاگین‌های ضروری

به **افزونه‌ها → افزودن جدید** بروید و این‌ها را نصب و فعال کنید:

- ✅ **Elementor** (الزامی برای طراحی صفحات)
- ✅ **WPForms** (الزامی برای فرم‌ها)
- 🟡 **Yoast SEO** (توصیه‌شده)
- 🟡 **Wordfence Security** (توصیه‌شده)
- 🟡 **UpdraftPlus** (بکاپ‌گیری)

---

## قدم ۴ — Import محتوای نمونه

1. به **ابزارها → وارد کردن (Import)** بروید.
2. روی **WordPress** کلیک → اگر نصب نیست، **Install Now** → سپس **Run Importer**.
3. فایل `sample-content.xml` (که در پوشه‌ی قالب است) را انتخاب کنید.
4. روی **Upload file and import** کلیک کنید.
5. نویسنده‌ی موجود را انتخاب کنید → **Submit**.

پس از این کار، ۵ صفحه ساخته می‌شود:
- خانه (`/home`)
- خدمات (`/services`)
- درباره من (`/about`)
- رزرو جلسه (`/booking`)
- تماس (`/contact`)

---

## قدم ۵ — تنظیم منو

1. به **نمایش → فهرست‌ها → ساختن یک فهرست جدید** بروید.
2. نام: `منوی اصلی`.
3. صفحات: خانه، خدمات، درباره من، رزرو جلسه، تماس را تیک بزنید و **Add to Menu**.
4. در **Display location** → تیک **منوی اصلی**.
5. **ذخیره‌ی فهرست**.

---

## قدم ۶ — تنظیم صفحه‌ی اصلی

1. به **تنظیمات → خواندن** بروید.
2. **Your homepage displays** → **A static page**.
3. **Homepage** → صفحه‌ی «خانه» را انتخاب کنید.
4. **Posts page** → یک صفحه‌ی جدید به نام «وبلاگ» بسازید و انتخاب کنید (اختیاری).
5. **Save Changes**.

---

## قدم ۷ — تنظیم پیوندهای یکتا

1. به **تنظیمات → پیوندهای یکتا** بروید.
2. گزینه‌ی **نام نوشته (Post name)** را انتخاب کنید.
3. **Save Changes**.

---

## قدم ۸ — تنظیم زبان فارسی و RTL

1. به **تنظیمات → همگانی** بروید.
2. **Site Language** → `فارسی` را انتخاب کنید.
3. **Timezone** → `Asia/Tehran`.
4. **Save Changes**.

برای تاریخ شمسی، پلاگین **WP Persian** یا **Jalali Date** را نصب کنید.

---

## قدم ۹ — تنظیمات قالب (Customizer)

به **نمایش → سفارشی‌سازی → تنظیمات قالب مریم قابل** بروید:

### اطلاعات تماس
- **ایمیل** (پیش‌فرض: `info@maryamghabel.ir`)
- **شماره تلفن** (placeholder — مریم قابل پر می‌کند)
- **واتساپ**، **اینستاگرام**، **تلگرام** (placeholder)
- **نشانی** (placeholder)
- **ساعات کاری** (پیش‌فرض: «شنبه تا چهارشنبه، ۹ تا ۱۸»)

### ادغام فرم‌ها
- بعد از ساخت فرم در WPForms، شناسه‌ی فرم را اینجا وارد کنید.

### لوگو و هویت
- به **هویت سایت** در همان بخش بروید و لوگو را آپلود کنید.

---

## قدم ۱۰ — ساخت فرم‌های WPForms

### فرم رزرو جلسه
1. به **WPForms → Add New** بروید.
2. نام فرم: «فرم رزرو جلسه».
3. فیلدها: Name, Email, Phone, Dropdown (نوع جلسه), Dropdown (نحوه برگزاری), Paragraph Text, Checkbox.
4. ذخیره → شناسه‌ی فرم (مثلاً `123`) را از URL بردارید.
5. به **Customizer → تنظیمات قالب مریم قابل → ادغام فرم‌ها → شناسه‌ی فرم رزرو WPForms** بروید و `123` را وارد کنید.

### فرم تماس
همین کار را برای یک فرم تماس ساده تکرار کنید.

---

## قدم ۱۱ — فعال‌سازی SSL

1. در cPanel → **Let's Encrypt SSL** یا **SSL/TLS** → گواهی رایگان برای `maryamghabel.ir` صادر کنید.
2. پلاگین **Really Simple SSL** را نصب و فعال کنید.
3. به **تنظیمات → SSL** بروید و **Activate SSL** را بزنید.

---

## قدم ۱۲ — امنیت پایه

- ✅ نام کاربری ادمین چیزی جز `admin` باشد.
- ✅ پسورد قوی (۱۶+ کاراکتر).
- ✅ احراز هویت دو مرحله‌ای (با **Wordfence Login Security**).
- ✅ فایل `.htaccess` — این کد را به انتها اضافه کنید:
  ```apache
  <Files wp-config.php>
      order allow,deny
      deny from all
  </Files>
  Options -Indexes
  ```

---

## قدم ۱۳ — بکاپ‌گیری

1. **UpdraftPlus** را نصب کنید.
2. به **تنظیمات → UpdraftPlus Backups → Settings** بروید.
3. **Files backup schedule**: Weekly.
4. **Database backup schedule**: Weekly.
5. مقصد: Google Drive یا Dropbox.
6. **Save Changes**.

---

## قدم ۱۴ — تست نهایی

1. در مرورگر `https://maryamghabel.ir` را باز کنید.
2. بررسی کنید:
   - ✅ صفحه‌ی خانه با Hero نمایش داده می‌شود.
   - ✅ منوی اصلی کار می‌کند.
   - ✅ روی لینک «خدمات» بزنید — صفحه‌ی خدمات باز شود.
   - ✅ فرم رزرو نمایش داده شود (WPForms یا فرم پیش‌فرض).
   - ✅ فونت Vazirmatn بارگذاری شده باشد.
   - ✅ در موبایل، منوی همبرگری باز شود.
3. در **PageSpeed Insights** سایت را تست کنید: <https://pagespeed.web.dev>

---

## قدم ۱۵ — بهینه‌سازی (اختیاری)

- پلاگین **WP Rocket** یا **LiteSpeed Cache** را نصب کنید.
- تصاویر را با **Smush** یا **ShortPixel** فشرده کنید.
- در Cloudflare ثبت کنید و DNS دامنه را منتقل کنید.

## کمک و عیب‌یابی

| مشکل | راه‌حل |
|---|---|
| قالب نمایش داده نمی‌شود | `wp-config.php` → `define('WP_DEBUG', true);` و خطا را ببینید. |
| منو نمی‌آید | فهرست را در **نمایش → فهرست‌ها** بسازید و **Display location → منوی اصلی**. |
| فونت نمی‌آید | CDN را تست کنید یا فونت را محلی میزبانی کنید (مراجعه به `assets/fonts/README.md`). |
| فرم کار نمی‌کند | شناسه‌ی WPForms در Customizer درست وارد شده باشد. |
| صفحه ۴۰۴ | به **تنظیمات → پیوندهای یکتا** بروید و **Save Changes** را دوباره بزنید. |
| تاریخ میلادی است | پلاگین **WP Persian** نصب کنید. |
